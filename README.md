# MMBC input images

Original benchmark input images, without resizing, cropping or re-encoding.

Scope: `original224`. Questions: 224; questions with images: 130; image files: 138.

`manifest.jsonl` maps official evaluator sample IDs to image files, image order, SHA-256 hashes, dimensions and source provenance. `statistics.json` records counts and byte sizes.

Only input images are included. Search-result images, reference answers and checklists are excluded. Image rights and dataset terms remain with their original owners.

This is an independent local Git repository. No GitHub remote has been created. Images are stored as actual bytes, without Git LFS.
